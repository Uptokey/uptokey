# Uptokey terminal contract

The canonical engineering and acceptance contract is [PROJETO-TUI-CANONICA.md](../../../../quimera/tui/PROJETO-TUI-CANONICA.md).

One frontend uses the shared Uptokey core, controller, identity, vault, project authorization and W5 receipts. English is the default; ten explicit locales are supported. Ordinary letters remain text. Provider/model selection, context, media, editing, clipboard, approvals and reconnect must reach their real canonical services. Archived implementations are never runtime fallbacks.
